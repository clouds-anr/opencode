## Primary install paths

GitHub Releases are the source of truth for all OpenCode CLI distribution artifacts.
Every supported install channel is updated automatically from the same release pipeline
that produced the binaries for a given tag.

### macOS

<Tabs>
  <Tab title="Homebrew (primary)">
    ```bash
    brew install anomalyco/tap/opencode
    ```

    Upgrade:
    ```bash
    brew upgrade opencode
    ```

    Uninstall:
    ```bash
    brew uninstall opencode
    brew untap anomalyco/tap   # optional, removes the tap
    ```
  </Tab>
  <Tab title="npm global">
    ```bash
    npm install -g opencode-ai@latest
    ```

    Upgrade:
    ```bash
    npm install -g opencode-ai@latest
    ```

    Uninstall:
    ```bash
    npm uninstall -g opencode-ai
    ```
  </Tab>
  <Tab title="Direct installer">
    ```bash
    curl -fsSL https://opencode.ai/install | bash
    ```

    Upgrade: re-run the same command.

    Uninstall:
    ```bash
    rm -f "$(which opencode)"
    ```
    Then remove the `PATH` entry the installer added to your shell profile.
  </Tab>
</Tabs>

## Installation directory (script installer)

When using the direct installer script, the binary is placed in the first writable
location from this priority list:

| Priority | Path |
|----------|------|
| 1 | `$OPENCODE_INSTALL_DIR` — explicit override |
| 2 | `$XDG_BIN_DIR` — XDG Base Directory |
| 3 | `$HOME/bin` — if it already exists |
| 4 | `$HOME/.opencode/bin` — fallback |

```bash
# examples
OPENCODE_INSTALL_DIR=/usr/local/bin curl -fsSL https://opencode.ai/install | bash
XDG_BIN_DIR=$HOME/.local/bin curl -fsSL https://opencode.ai/install | bash
```

## Install a specific version

```bash
# direct installer
curl -fsSL https://opencode.ai/install | bash -s -- --version 0.3.14

# npm
npm install -g opencode-ai@0.3.14

# Homebrew (pin)
brew install anomalyco/tap/opencode@0.3.14
```
